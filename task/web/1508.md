   * Bảo vệ toàn bộ layout `/admin/*` bằng `RequireAdmin` guard; Backend kiểm tra role `PLATFORM_ADMIN` nghiêm ngặt và trả `403` nếu tài khoản không đủ thẩm quyền.

### 📦 PHẦN 0: Chuẩn Bị API Client Admin & Script Kiểm Thử Kết Nối (Sprint 29A)
* **Mục tiêu:** Xây dựng module `adminApi.ts` chuyên biệt kết nối Backend Gateway (`http://localhost:3000/api/v1`), hỗ trợ đầy đủ các thao tác quản trị nền tảng.
* **Chi tiết công việc:**
  1. **Xây dựng `web/src/ui/api/adminApi.ts`:**
     * `getAdminStats()`: Lấy số liệu thống kê tổng quan (Pending Businesses, Pending Stores, Total Books, Suspended Books).
     * `getPendingBusinesses(params)` / `getAllBusinesses(params)`: Lấy danh sách doanh nghiệp kèm bộ lọc trạng thái.
     * `approveBusiness(id)` / `rejectBusiness(id, reason)`: Phê duyệt / Từ chối doanh nghiệp.
     * `getPendingStores(params)` / `getAllStores(params)`: Lấy danh sách cửa hàng.
     * `approveStore(id)` / `rejectStore(id, reason)`: Phê duyệt / Từ chối cửa hàng.
     * `getAdminBooks(params)`: Lấy danh sách sách toàn sàn (kèm trạng thái ACTIVE/SUSPENDED/DRAFT).
     * `suspendBook(id, reason)` / `activateBook(id)`: Khóa sách vi phạm / Mở lại sách.
     * `getServiceHealth()`: Gọi endpoint Gateway `/health/services` kiểm tra trạng thái 6 microservices.
  2. **Script kiểm tra nhanh Part 0:** `scripts/verify-phase8-part0.mjs` kiểm tra gọi các endpoint thật với Token `PLATFORM_ADMIN`.
* **Tiêu chí nghiệm thu:** Script Part 0 chạy 100% PASS, xác thực Token `PLATFORM_ADMIN` thành công.

* **Kịch bản kiểm thử (8 bước xuyên suốt):**
  1. **Step 0:** Service Live Check & Verify `PLATFORM_ADMIN` Token.
  2. **Step 1:** User đăng ký Doanh nghiệp mới $\rightarrow$ Kiểm tra Doanh nghiệp xuất hiện trong hàng chờ Admin `PENDING`.
  3. **Step 2:** Admin HUKI duyệt Doanh nghiệp $\rightarrow$ Doanh nghiệp chuyển sang `APPROVED`.
  4. **Step 3:** Doanh nghiệp tạo Store mới $\rightarrow$ Admin HUKI kiểm tra và duyệt Store `APPROVED`.
  5. **Step 4:** Doanh nghiệp đăng bán Sách mới $\rightarrow$ Admin HUKI kiểm tra sách trên Catalog toàn sàn.
  6. **Step 5:** Admin HUKI thực hiện khóa sách vi phạm (`SUSPENDED`) $\rightarrow$ Kiểm tra Buyer không thể mua/xem sách.
  7. **Step 6:** Admin HUKI mở khóa lại sách (`ACTIVE`) $\rightarrow$ Sách tái xuất hiện trên Storefront.
  8. **Step 7:** Kiểm tra Gateway `/health/services` trả về healthy cho tất cả các dịch vụ.
