### 📦 PHẦN 0: Chuẩn Bị Tích Hợp API Catalog, Order & Business Scope (Sprint 25A)
* **Mục tiêu:** Kiểm tra và hoàn thiện các hàm API Client kết nối Backend Gateway (`catalogApi.ts`, `orderApi.ts`, `businessApi.ts`), đảm bảo các request luôn truyền đúng `businessId` và Token phân quyền.
* **Chi tiết công việc:**
  1. **Nâng cấp `catalogApi.ts`:**
     * `createBook(payload)`: Hỗ trợ tạo sách thật với đủ các trường định dạng (Physical, Digital, Hybrid), giá bán, tác giả, thể loại, kho hàng.
     * `updateBook(bookId, payload)`: Cập nhật thông tin sách.
     * `updateBookStock(bookId, stock)`: Cập nhật tồn kho sách an toàn.
     * `updateBookStatus(bookId, status)`: Chuyển đổi trạng thái (ACTIVE, HIDDEN, ARCHIVED).
  2. **Nâng cấp `orderApi.ts`:**
     * `getSellerOrders(businessId, filters)`: Lấy danh sách đơn hàng lọc theo trạng thái.
     * `getSellerOrderDetail(orderId)`: Lấy chi tiết đơn hàng (người nhận, địa chỉ, items, timeline).
     * `updateOrderStatus(orderId, status, payload)`: Chuyển trạng thái đơn (`CONFIRMED`, `PROCESSING`, `SHIPPED`, `DELIVERED`, `CANCELLED` kèm `cancelReason`).
  3. **Script kiểm tra nhanh Part 0:** `scripts/verify-phase7-part0.mjs` kiểm tra gọi các endpoint thật trên cổng `:3000`.
* **Tiêu chí nghiệm thu:** Script Part 0 chạy 100% PASS, dữ liệu trả về đúng chuẩn.
