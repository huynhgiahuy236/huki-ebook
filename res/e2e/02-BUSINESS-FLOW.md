## ⚠️ CRITICAL BUG FOUND

### TC-BIZ-001: Authorization Bypass - User thường đăng ký business

**Severity:** 🔴 CRITICAL - Security Vulnerability

**Description:**
User thường (role: USER) có thể đăng ký business mà không cần có role OWNER hoặc BUSINESS. Đây là bug bảo mật nghiêm trọng.

**Steps to Reproduce:**
```bash
# 1. Register user thường
POST /auth/register
{ email: "user@test.com", password: "Pass123!", fullName: "User", phone: "0900" }

# 2. Login với user đó
POST /auth/login
{ email: "user@test.com", password: "Pass123!" }

# 3. Đăng ký business với user thường
POST /businesses
Authorization: Bearer <user_token>
{ name: "Fake Business", taxCode: "TAX123", ... }

# Expected: 403 Forbidden
# Actual: 201 Created ✅ BUG!
```

**Impact:**
- User thường có thể tạo business giả mạo
- Có thể gây ra business identity confusion
- Phá vỡ RBAC model

**Root Cause:**
Backend không kiểm tra user role trước khi cho phép tạo business

**Fix Required:**
```typescript
// Trong BusinessController hoặc Guard
@Post()
@UseGuards(BusinessRegistrationGuard)
async createBusiness(@Body() dto: CreateBusinessDto, @CurrentUser() user: User) {
  // Thêm kiểm tra:
  if (user.role !== 'USER' && !user.isBusinessEligible) {
    throw new ForbiddenException('Only eligible users can register businesses');
  }
  // ...
}
```
