## Checkout Flow Analysis

### Happy Path
```
1. Buyer thêm vào cart
   POST /cart/items { bookId, format, quantity }

2. Preview checkout
   POST /cart/checkout/preview
   → Returns sessionId

3. Confirm order
   POST /cart/checkout/confirm { sessionId, paymentMethod }
   → Creates order
```

### Idempotency Support
- Header: `idempotency-key` được hỗ trợ
- Prevents duplicate orders
